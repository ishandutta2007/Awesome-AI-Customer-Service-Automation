## 🏢 SaaS / Commercial Platforms

The AI chatbot and virtual assistant market spans **enterprise CRM-integrated bots** (Salesforce Einstein Bots, Agentforce) that provide **deep customer data integration**, **AI-native customer service platforms** (Intercom Fin, Ada) that focus on **autonomous resolution and outcome-based pricing**, and **conversational AI platforms** (Kore.ai, Cognigy, Yellow.ai) that offer **multi-channel deployment and enterprise governance**. **Einstein Bots** is included in **Service Cloud Unlimited Edition** with **Digital Engagement at $75/user/month** [citation:1]. **Intercom Fin** charges **$0.99 per outcome** with **Essential at $29/seat/month** [citation:2]. **Ada** is **enterprise-only** with **no public self-serve pricing** — base contracts start around **$30,000/year** [citation:14]. **Kore.ai** offers **5,000 free sessions** with consumption-based pricing [citation:5].

## 🔓 Open-Source GitHub Projects

*Sorted by GitHub_Stars_Count (Descending)* 🌟

- **[Langflow](https://github.com/langflow-ai/langflow)** [![Stars](https://img.shields.io/github/stars/langflow-ai/langflow?style=social&color=white)](https://github.com/langflow-ai/langflow/stargazers)  
  **Visual framework for building multi-agent and RAG applications**, MIT licensed. **155K+ GitHub stars** — **the most accessible visual agent builder** . **Drag-and-drop interface for LangChain components** . **Built-in RAG pipelines** . **The most popular open-source conversational AI builder** [citation:11]. 🎯

- **[Rasa](https://github.com/RasaHQ/rasa)** [![Stars](https://img.shields.io/github/stars/RasaHQ/rasa?style=social&color=white)](https://github.com/RasaHQ/rasa/stargazers)  
  **The leading open-source conversational AI framework**, Apache-2.0 licensed (core). **25M+ downloads** — **enterprise-grade on-premises deployment** . **Flows for business logic** — simplified way to describe conversation handling . **CALM for LLM-powered assistants** . **Full data sovereignty** — the only conversational AI platform that runs fully on-premises [citation:9][citation:20]. 🏛️

- **[Botpress](https://github.com/botpress/botpress)** [![Stars](https://img.shields.io/github/stars/botpress/botpress?style=social&color=white)](https://github.com/botpress/botpress/stargazers)
